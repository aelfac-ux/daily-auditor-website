AI × AUDIT · DAY 07 · PRACTICAL TOOLS

Level One: Build Your First AI Audit Assistant

The detective briefing is over. Install the tools, describe the audit test, and run your first procurement-anomaly script on your own computer.

Arthur Agent Editorial DeskJuly 2, 202611-minute read
FIELD CASEEight fictional purchases hide two unusually large transactions. You do not need to become a software engineer first: describe the test clearly, let approved AI draft Python, then run and verify it locally.

The script finds clues. You still decide whether they indicate error, control weakness, fraud risk, or a valid exception.

You are the investigator. AI is the assistant. Evidence remains the judge.

Level 1: install Python

Download Python from the official site. On Windows, select Add python.exe to PATH during installation. Open PowerShell and verify:

CHECK THE TOOL
python --version

If Windows cannot find that command, try py --version. Use a supported version approved by your organization; “newest” is not automatically “best for production.”

Level 2: build the VS Code base

  1. Install Visual Studio Code.
  2. Install Microsoft's official Python extension.
  3. Create and open a folder named ai-audit-lab.
  4. Create test.py and run the line below.
FIRST RUN
print("My audit-assistant lab is running")

Level 3: describe the procurement detective

Create purchase_data.csv with entirely synthetic fields for supplier, amount, date, and owner. Use the eight fictional rows from the Chinese tutorial or invent your own. Then give an approved AI system a bounded request:

A safer prompt

“Write an offline Python script that reads local purchase_data.csv, flags amounts above twice the overall average, calculates each owner's total and share, prints the findings, and writes result.csv. Add clear comments and input validation. Do not transmit data or call external services.”

AI will probably use pandas, averages, groupby, and CSV export. You do not need to understand every line immediately, but you must confirm that the rule matches your intent, paths are controlled, and no network function is present.

Level 4: run it locally

INSTALL AND RUN
py -m pip install pandas
py audit_analysis.py

The tutorial dataset totals 3,432,000. Its average is 429,000, so the two-times threshold is 858,000. Transactions of 980,000 and 1,500,000 are flagged. Moriarty handles 2,927,000—about 85.3% of the total. Concentration is a risk signal, not proof of misconduct.

An anomaly tells you where to investigate. Contracts, approvals, receipt evidence, and interviews tell you what happened.

Level 5: debug without leaking secrets

ModuleNotFoundError usually means pandas is missing from the selected environment. FileNotFoundError usually means the terminal is in the wrong folder or the CSV filename differs. For other errors, provide AI with the command, expected behavior, actual behavior, and the relevant traceback.

Before sharing an error, remove real paths, usernames, hostnames, filenames, credentials, keys, and company data. Error logs can be confidential too. “Copy the whole traceback” does not mean “upload it without inspection.”

CASE RESOLVED

Did we catch Moriarty?

Not yet. We found two unusually large transactions and a strong owner concentration. The next move is to inspect requests, quotes, approvals, receipts, and payments. The program narrows the field; the auditor completes the judgment.
