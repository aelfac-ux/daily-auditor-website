Make Your Disclosure Watcher Sail Every Day

A guide to Apps Script scheduling: move from code that runs to a process that works while you sleep.

Arthur Agent Editorial DeskJuly 5, 20269-minute read
FIELD CASEIf the captain wakes at 7 a.m. every day to press Run, that is not automation. It is manual work with an alarm clock.

Day 09 already built a watcher that fetches public data, deduplicates disclosures, and sends email. Today we give it a real sailing schedule.

Test the ship before scheduling departure. A trigger does not fix broken code; it merely makes the error punctual.

Where does Apps Script live?

Go to script.google.com and sign in with a Google account. Consumer Gmail and Google Workspace accounts can use Apps Script, although an organization administrator may restrict external requests, authorization, or mail.

Apps Script primarily uses JavaScript and works naturally with Gmail, Sheets, Drive, and external APIs. Day 09 requires external-request and send-mail authorization. It does not need your Gmail password, but you should read the requested scopes instead of approving them like a sailor enthusiastically signing a map he cannot read.

Some paid or enterprise products may add scheduling capabilities, so the claim is not “Colab can never be scheduled.” For this beginner email watcher, Apps Script provides the more direct trigger and authorization path.

Three checks before scheduling

  1. Manual run succeeds: confirm Day 09's monitorTsmcMajorMessages can fetch data and send mail when a new disclosure exists.
  2. Authorization is complete: installable triggers run as their creator. An alarm clock cannot grant missing permissions.
  3. Time zone is correct: set the project to Asia/Taipei, or 7 a.m. may arrive in a different ocean.

Method 1: create the trigger in the editor

  1. Open the Day 09 Apps Script project.
  2. Select the clock icon, Triggers.
  3. Choose Add Trigger.
  4. Select monitorTsmcMajorMessages.
  5. Choose Time-driven as the event source.
  6. Choose Day timer.
  7. Select the 7 a.m.–8 a.m. window.
  8. Save and confirm that the trigger appears in the list.

Apps Script selects a time within the chosen hour; it does not promise 07:00:00 exactly. This is a patrol boat, not a rocket launch.

Method 2: create it in code without duplicate alarms

TRIGGER SETUP
function createDailyTrigger() {
  ScriptApp.getProjectTriggers()
    .filter(function (trigger) {
      return trigger.getHandlerFunction() === "monitorTsmcMajorMessages";
    })
    .forEach(function (trigger) {
      ScriptApp.deleteTrigger(trigger);
    });

  ScriptApp.newTrigger("monitorTsmcMajorMessages")
    .timeBased()
    .everyDays(1)
    .atHour(7)
    .create();
}

Run createDailyTrigger once manually. It removes previous triggers for the watcher before creating a new one, preventing three clicks from summoning three lookouts.

How do you know the ship did not hit a reef?

The Executions panel records function, time, status, and errors. Google generally emails a failure summary when an installable trigger fails. Check the following:

  • the latest scheduled run completed;
  • the API, network, authorization, or schema did not change;
  • no email may be correct because Day 09 found no new disclosure;
  • mail quota remains available through MailApp.getRemainingDailyQuota();
  • unused triggers and permissions are removed.

Three common ghost ships

The wrong function

Scheduling createDailyTrigger rebuilds the alarm every day. Schedule monitorTsmcMajorMessages.

No email is mistaken for failure

Day 09 intentionally sends nothing when there is no new disclosure. Check Executions and logs before declaring the ship missing.

Duplicate triggers

Multiple triggers repeat execution, consume quota, and create confusion. Review the trigger list periodically even when deduplication prevents repeated mail.

CASE RESOLVED

The captain overslept; the watcher still sailed

The user tests manually, grants authorization, confirms Asia/Taipei, and creates a 7–8 a.m. trigger. On the next quiet day, the run succeeds without email. When a new disclosure appears, one notification is sent. The captain wakes thirty minutes late and the world somehow continues—now that is automation.

Captain's verdict

Automation gives fixed actions to systems and returns human time to judgment. You own direction, rules, and review; AI helps chart the route; Apps Script sails each day. Still read the log occasionally—silence can mean calm seas, or that the ship disappeared last Tuesday.
