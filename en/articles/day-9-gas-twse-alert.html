Build a TWSE Disclosure Email Watcher with AI and Google Apps Script

You do not need to become an engineer before you automate one useful watch. Define the task clearly, then let AI help put a lookout in the crow's nest.

Arthur Agent Editorial DeskJuly 4, 202613-minute read
FIELD CASEOpening the disclosure website and searching for company code 2330 every day is like making the captain climb the mast at dawn—heroic, theatrical, and an inefficient use of the captain.

Our Apps Script checks public TWSE data and sends email only when it finds a disclosure that has not already been reported.

For a beginner, programming starts with four questions: Where is the data? What should be selected? When should the system alert me? How will it avoid repeating itself?

What are we building?

Google Apps Script is Google's browser-based cloud scripting platform. This project uses UrlFetchApp to retrieve an external public dataset and MailApp to send email. It never needs your Gmail password, although Google will ask you to review and authorize the required scopes on the first run.

Our source is the Taiwan Stock Exchange OpenAPI dataset for daily material information published by listed companies:

TWSE OPENAPI
https://openapi.twse.com.tw/v1/opendata/t187ap04_L

Public APIs can change fields, schedules, or availability. Recheck the official catalog before production use. This tutorial is neither a real-time trading system nor investment advice.

Give AI a seaworthy brief

Prompt template

“Write Google Apps Script that reads the TWSE OpenAPI endpoint, filters company code 2330, formats date, time, subject, and explanation, and emails only disclosures that have not been sent before. Use Script Properties for deduplication, validate HTTP status and JSON shape, never request a Gmail password, add beginner comments, and explain how to create a daily time-driven trigger.”

A good prompt names the platform, source, filter, output, security boundary, error handling, and duplicate policy. A treasure map that says only “sail that way” is mostly an invitation to meet rocks.

Set up the project

  1. Open script.google.com and create a project.
  2. Set the project time zone to Asia/Taipei.
  3. Paste the code below.
  4. Replace yourname@example.com with your own address; do not publish it in a public repository.
  5. Run monitorTsmcMajorMessages, review the requested permissions, and authorize only what you understand.
  6. After a successful test, run createDailyTrigger once.
COMPLETE GOOGLE APPS SCRIPT
const API_URL = "https://openapi.twse.com.tw/v1/opendata/t187ap04_L";
const TARGET_CODE = "2330";
const TARGET_NAME = "TSMC";
const TO_EMAIL = "yourname@example.com";

function monitorTsmcMajorMessages() {
  const response = UrlFetchApp.fetch(API_URL, {
    muteHttpExceptions: true,
    headers: { Accept: "application/json" }
  });
  const status = response.getResponseCode();
  if (status !== 200) throw new Error("TWSE API failed: HTTP " + status);

  const raw = JSON.parse(response.getContentText("UTF-8"));
  if (!Array.isArray(raw)) throw new Error("Unexpected API format");

  const rows = raw.map(function (item) {
    const clean = {};
    Object.keys(item).forEach(function (key) {
      clean[String(key).trim()] = item[key];
    });
    return clean;
  });

  const matches = rows.filter(function (item) {
    return String(item["公司代號"] || "").trim() === TARGET_CODE;
  });
  const props = PropertiesService.getScriptProperties();
  const newItems = matches.filter(function (item) {
    return props.getProperty(messageId(item)) !== "sent";
  });
  if (newItems.length === 0) return console.log("No new disclosures");

  MailApp.sendEmail({
    to: TO_EMAIL,
    subject: "Material information: " + TARGET_CODE + " " + TARGET_NAME,
    body: buildEmailBody(newItems)
  });
  newItems.forEach(function (item) {
    props.setProperty(messageId(item), "sent");
  });
}

function messageId(item) {
  const source = [item["發言日期"], item["發言時間"], item["主旨"]].join("|");
  const bytes = Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, source);
  return "sent_" + Utilities.base64EncodeWebSafe(bytes);
}

function buildEmailBody(items) {
  const lines = ["TWSE material-information watch", "",
    "Company: " + TARGET_CODE + " " + TARGET_NAME,
    "New disclosures: " + items.length, ""];
  items.forEach(function (item, index) {
    lines.push("Item " + (index + 1));
    lines.push("Date: " + (item["發言日期"] || ""));
    lines.push("Time: " + (item["發言時間"] || ""));
    lines.push("Subject: " + (item["主旨"] || ""));
    lines.push("Details: " + (item["說明"] || ""), "----------------", "");
  });
  lines.push("Source: " + API_URL);
  return lines.join("\n");
}

function createDailyTrigger() {
  ScriptApp.getProjectTriggers()
    .filter(function (t) { return t.getHandlerFunction() === "monitorTsmcMajorMessages"; })
    .forEach(function (t) { ScriptApp.deleteTrigger(t); });
  ScriptApp.newTrigger("monitorTsmcMajorMessages")
    .timeBased().everyDays(1).atHour(18).create();
}

The program's six duties

  1. Fetch daily material information through HTTPS.
  2. Check the HTTP response and JSON structure.
  3. Trim field names and filter code 2330.
  4. Create an identifier from disclosure date, time, and subject.
  5. Email only new disclosures, then record them as sent.
  6. Run daily through an installable time-driven trigger.

Installable triggers run as the account that created them, may fire within a window around the selected hour, and remain subject to Apps Script quotas. Even an automated ship has limited provisions.

Authorization and safety

  • UrlFetchApp requires external-request scope; MailApp requires send-mail scope.
  • MailApp sends mail but cannot read your Gmail inbox.
  • Never publish real addresses, API keys, cookies, tokens, or company data.
  • Inspect AI-generated code for unexpected URLs or data transmission before running it.
  • Monitor failure notifications and API schema changes.

When the ship hits an error

Give AI the error message, executed function, expected behavior, and actual behavior. Ask for an explanation first and the smallest correction second. Remove email addresses, project identifiers, authorization details, and private data before sharing logs. Detailed logs are useful to both debuggers and attackers.

CASE RESOLVED

From repeated searching to reviewing only new disclosures

The auditor tests the script manually, then creates a daily trigger. On a quiet day it sends nothing. When a new disclosure appears, it sends one message and records the identifier; later runs do not resend it. Human time goes to reading the disclosure and assessing risk—not refreshing a page.

Captain's verdict

AI coding is not about becoming an engineer overnight. It is about turning “I wish someone watched this every day” into a small tool that can be executed, tested, and repaired. Start small, verify first, automate second. Keep the compass; AI is the sailor who sometimes holds the chart upside down but rows remarkably fast.
